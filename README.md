# iris

Apple TV remote for Android: a backend that controls the Apple TV, a web remote, and a native Android app.

| Folder | What |
|---|---|
| `backend/` | API that controls the Apple TV (moving from NestJS to Python + pyatv) |
| `web/` | Web remote (Vue/Quasar) |
| `android/` | Android app (Kotlin/Compose) |
| `specs/` | Plans, decisions and the progress log |

See each folder's README for how to run it, and [specs/README.md](specs/README.md) for project status.
